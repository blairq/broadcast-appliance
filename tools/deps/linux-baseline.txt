# ============================================================================
# tools/deps/linux-baseline.txt — La BASE del sistema que el bundle puede usar
#
# Todo lo que NO esta aca tiene que viajar dentro del bundle (bin/64bit/),
# compilado desde fuente fijada. tools/deps/check-portable.sh lo verifica sobre
# cada ELF del bundle y `make release` falla si algo se escapa.
#
# Criterio (el mismo que usan AppImage y los binarios oficiales de Qt): solo
# interfaces que TIENEN que ser las del sistema porque hablan con el kernel,
# los drivers o los servidores de la sesion, y que estan en cualquier Linux de
# escritorio:
#   - glibc (C, math, hilos, dlopen, resolver)       -> el kernel/ld.so
#   - GL/EGL/GLX/Vulkan (cargadores de drivers)     -> los drivers de video
#   - X11/xcb/Wayland/xkbcommon                     -> el servidor grafico
#   - ALSA/PulseAudio                               -> el servidor de audio
#   - udev, drm                                     -> dispositivos del kernel
#   - fontconfig/freetype                           -> las fuentes del sistema
#   - glib/gthread/gmodule/gio/dbus/gssapi, zlib/zstd/bz2, libatomic
#                                                   -> lo que exige Qt oficial
#     (gmodule: Qt PDF; bz2 y libatomic: el motor FFmpeg de Qt Multimedia)
# libstdc++/libgcc_s: el bundle lleva los suyos en bin/64bit/cxx/ y el
# launcher usa el mas nuevo (el del sistema si es igual o mas nuevo).
# ============================================================================
