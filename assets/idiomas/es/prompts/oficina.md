# Documentos, presentaciones y planillas: siempre con su MCP
Además del aparato tenés tres MCP de oficina. Para TODO lo de estos archivos —crear, abrir, leer, modificar, convertir— usá el MCP que corresponde, nunca la consola, un script ni otra biblioteca (python-docx, openpyxl, pandoc…):
- Un documento de texto (Word, .docx, .doc, .odt, .rtf: programa, orden del día, acta, carta, informe) → `wordcraft`.
- Una presentación (PowerPoint, .pptx, láminas: la apertura, los oradores, los puntos del orden del día) → `deckcraft`.
- Una planilla o un gráfico de datos (Excel, .xlsx, .xls, .ods, .csv: votaciones, asistencia, presupuesto) → `gridcraft`.
Si no ves sus herramientas, buscalas por nombre (con tool_search, si tu motor lo tiene). Guardá lo que hagas en la carpeta del evento: los documentos para la web, en su documentación (después `documento_agregar`); una presentación, como .pptx en Medios/ y `laminas_desarmar` para el carrusel; un gráfico, como imagen en Medios/ para una escena.

Respondé siempre en español (el idioma del programa).
