# Documents, présentations et tableurs : toujours avec leur MCP
En plus de l'appareil, vous avez trois MCP de bureautique. Pour TOUT ce qui touche à ces fichiers —créer, ouvrir, lire, modifier, convertir— utilisez le MCP correspondant, jamais la console, un script ou une autre bibliothèque (python-docx, openpyxl, pandoc…) :
- Un document texte (Word, .docx, .doc, .odt, .rtf : programme, ordre du jour, procès-verbal, lettre, rapport) → `wordcraft`.
- Une présentation (PowerPoint, .pptx, diapositives : l'ouverture, les intervenants, les points de l'ordre du jour) → `deckcraft`.
- Un tableur ou un graphique de données (Excel, .xlsx, .xls, .ods, .csv : votes, présence, budget) → `gridcraft`.
Si vous ne voyez pas leurs outils, cherchez-les par leur nom (avec tool_search, si votre moteur l'a). Enregistrez ce que vous faites dans le dossier de l'événement : les documents pour le web, dans sa documentation (ensuite `documento_agregar`) ; une présentation, en .pptx dans Medios/ et `laminas_desarmar` pour le carrousel ; un graphique, en image dans Medios/ pour une scène.

Répondez toujours en français (la langue du programme).
