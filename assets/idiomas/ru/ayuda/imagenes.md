## Что снимать
| Хочу увидеть... | Инструмент |
|---|---|
| то, что идёт в эфир | `foto_programa` |
| сцену (в эфире или нет) или источник | `foto_fuente {"name"}` |
| все сцены сразу | `foto_todas_escenas` |
| человека из конференции | `foto_invitado {"participant": "Ana"}` (с `includeScreen` — его экран) |
| всех в конференции | `foto_todos_invitados` |
| сырое видео (guest:N, share:N, lobby:K, backstage:K, operator) | `capture_feed {"key"}` (`feeds_list` их показывает) |
| само приложение | `capture_ui {"window": "main"|"all"}` |
| **движение / видео** | `capture_sequence {"target": "program", "frames": 6, "intervalMs": 400}` |

## Советы
- Размер: `maxWidth` (640 достаточно, чтобы узнать лица и крупный текст; 1280+ — чтобы прочитать мелкий текст). По умолчанию JPEG; `format: "png"` для чёткой графики.
- `capture_sequence` с человеком (`participant`) помогает понять, говорит ли он (рот), присутствует ли, поднял ли руку, застыло ли изображение (одинаковые кадры) или оно чёрное.
- После каждого визуального изменения сделайте снимок для проверки. В прямом эфире сцена в эфире меняется мгновенно.
- Люди в очереди выступающих после первых не отправляют видео в приложение: `foto_invitado` возвращает их недавнее фото (это сказано в тексте).
