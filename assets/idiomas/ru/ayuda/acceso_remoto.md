Три пути, **по одному за раз** (Настройки → «Доступ из интернета»): **Pinggy** (обычный), **Cloudflare** (домен организации в Cloudflare) и **Собственный туннель (WireGuard)** (сервер с публичным IP). Смена любого из них перезапускает конференцию: **никогда во время мероприятия в эфире** (инструменты это отклоняют).

## Pinggy: с API key всё само
У аккаунта Pro в pinggy **два разных ключа**: **API key** (управляет аккаунтом) и **токен туннеля** (открывает туннель). **Оператору нужно передать вам только API key**; токен приложение получит само.
1. `acceso_remoto_clave {"tipo": "api_key", "clave": "…"}`: сохраняет его зашифрованным (никогда не возвращается и не пишется в журнал; не повторяйте его в чате).
2. `acceso_remoto_configurar_con_api_key {}`: запрашивает у аккаунта токен (сохраняет его зашифрованным), его **постоянный поддомен** (что-то.a.pinggy.link) и **постоянный TCP-порт** (для видео внешних участников) и с ними включает туннель. С `{"subdominio": "salaconcejo"}` (только строчные буквы и цифры: pinggy не принимает дефисы) сначала **меняет поддомен в аккаунте** (получится salaconcejo.a.pinggy.link); если pinggy его не даёт (занят или недопустим), сообщает об этом: предложите другое имя.
3. `acceso_remoto_estado`: дождитесь `pinggy.estado` = `listo` и передайте оператору `pinggy.urlPublica` и `enlaces` (гости, удалённое заседание, аудитория). Чтобы отсканировать: `qr_mostrar`.
- `acceso_remoto_panel`: какие туннели активны у аккаунта, с точки зрения pinggy. `acceso_remoto_cortar_tuneles`: обрывает их все (например, другое устройство осталось с тем же токеном: pinggy допускает **один туннель на токен**).
- **Не вставляйте API key как токен** (`tipo: "token"`): туннель не откроется (pinggy отвечает «не аутентифицирован»), и приложение предупредит, что они одинаковые. Токен вручную (`tipo: "token"`) — только если нет API key.
- `acceso_remoto_configurar` меняет остальное (регион, собственный домен с `host` и `cname_destino`, TURN, белый список). Домен организации: `acceso_remoto_dns_instrucciones` готовит текст для того, кто управляет DNS, а `acceso_remoto_dns_verificar` проверяет CNAME.
- Без плана Pro (без токена): работает и так, в бесплатном режиме, 60 минут, случайный адрес и с баннером pinggy, который гостям нужно принять.

## Cloudflare
Нужен **токен туннеля Cloudflare** (Zero Trust → Networks → Tunnels): `acceso_remoto_clave {"tipo": "cloudflare", "clave": "…"}`, затем `settings_set {"values": {"gateway.tunnel": true, "gateway.tunnelHost": "sala.midominio.com"}}`. Без токена он выключен.

## Собственный туннель (WireGuard)
Собственный сервер с публичным IP: `settings_set` с `wg.enabled`, `wg.endpoint` (host:порт), `wg.serverKey`, `wg.address`, `wg.publicAddress`. Это лучший путь для видео, но кто-то должен был заранее настроить сервер.
