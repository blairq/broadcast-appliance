## Возможности
API Facebook транслирует и управляет видео только **Страниц** (не личного профиля). Аккаунт должен администрировать хотя бы одну Страницу.

## Настроить (один раз)
1. `facebook_status`: говорит, не хватает ли приложения, аккаунта или Страницы, и показывает URI перенаправления.
2. Приложение Meta: на https://developers.facebook.com/apps/ создать приложение (тип **Business**), добавить **Вход через Facebook** и указать в «Действительные URI перенаправления OAuth» `redirectUri` из `facebook_status` (по умолчанию `http://localhost:8791/`). Режима разработки достаточно (им пользуются только его администраторы). ID и секретный ключ — в Настройки -> Основное: сохраняются через защищённую форму `account_credentials_request {"platform": "facebook"}` (ключ не должен проходить через чат).
3. `facebook_login`: открывает браузер; ЧЕЛОВЕК выбирает аккаунт, отмечает Страницы и соглашается. Затем `facebook_pages` (и `{"select": "..."}`, если их несколько).

## Транслировать
- `facebook_live_create {"title": "...", "test": true}` создаёт эфир **без публикации** (его видит только Страница в Live Producer) и транслирует из приложения (RTMPS, сервер и ключ только в памяти). Проверить через `foto_programa` и `facebook_live_list {"id"}`; когда всё в порядке, `facebook_live_publish {"id"}` делает его публичным без обрыва.
- `test: false`: сразу выходит публично.
- Завершить: `facebook_live_end` (без `id` — эфир, в который транслирует приложение). Остаётся как видео.

## Видео
`facebook_videos`, `facebook_video_update {"id", "title", "description"}` (или `"delete": true`), `facebook_video_upload` (без `path` — последняя запись).

## Комментарии
- При трансляции сами выбираются комментарии эфира; `facebook_chat {"live": id}` выбирает другой, `{"send": "texto"}` комментирует от имени Страницы.
- На экране: `chat_overlay_add {"channel": "facebook"}` (или `all`).
