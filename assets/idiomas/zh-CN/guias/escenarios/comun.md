# 准备活动：流程（适用于所有类型）

准备活动**不是**照操作员说的去做：而是手把手带他做出一场能顺利进行的活动，不需要他记得去要每一样东西。你没问到的，活动当天就会缺。

## 1. 搭建任何东西**之前**先访谈

把场景指南里的问题分几次问（每条消息三四个，尽量给出选项：“现场、远程，还是两者都有？”）。操作员不知道的，提出合理的默认值（“如果你不确定，我就定为 90 分钟”）。动手之前，用一份简短的清单总结你要搭建的内容，并请对方确认。

无论什么活动，都要问：
- 名称、日期、开始时间、时长和**时区**（没有时区，远程的人就不知道是几点）。
- 谁来、怎么来：多少人？现场、远程，还是两者都有？有要发言的嘉宾吗（通过浏览器进入会议室）？有观看（活动网页）并提问的观众吗？
- 需要给人登记吗？用什么联系他们：邮箱、WhatsApp、Telegram？要给他们发带链接和二维码的邀请吗？
- 要推流吗（YouTube、Twitch、Facebook、其他平台）？要录制吗？
- 有议程、议题列表或段落吗？每部分谁发言、讲多久？
- 有要分享的文件吗（PDF、演示文稿、阅读材料）？要在屏幕上显示吗？
- 视觉形象：机构标志、省徽或国徽、配色、背景图片？（索要文件或去找；见下面的“图片”。）
- 等待和间歇时的背景音乐或片头音乐？
- 主持人或演讲者需要提词器吗？
- 要翻译成其他语言吗（字幕或语音）？给谁？
- 会场里有屏幕（电视）吗？有打印的或屏幕上的二维码吗？
- 活动当天谁来操作、在哪里操作（这台机器、平板：控制台）？

## 2. 按顺序搭建

1. 活动（evento_nuevo / evento_armar），带日期、时间、时区、时长和带时间的段落。用 evento_nuevo 加 abrir 之后，程序会重启，对话会自动继续。
2. 人员：padron_anotar，带角色（发言人、嘉宾、成员、学生……）、参加方式和联系方式（邮箱、WhatsApp）。要表决的：`vota: true`。
3. 场景：每个环节一个（开场、主持、嘉宾、演示、PDF、结束），如果议题变化，每个议题配一张自己的图片。文件用的场景：pdf_escena_crear。
4. 图形：带真实**姓名**和**职务**的字幕条，每个段落的标题垫片画面。文字放在提示点的 `valores` 中（不是 `parametros`）；在屏幕上停留多久，用值中的 `salidaEn`（ms）（0 = 一直显示）。放进串联单之前先用 grafico_probar 测试。
5. 提词器：每部分一篇讲稿（prompter_escribir），并在串联单中放对应的提示点。
6. 文档：documento_agregar（或 pdf_convertir），附描述，并关联到对应议题或部分。找操作员提到的文件；如果没有，建议添加什么。
7. 活动网页（evento_web）：标题、描述、轻量的图片、文件。
8. 音乐（media_list、playlist_crear）、标志和徽章（DSK 图层：dsk_definir）、需要时的翻译（traduccion_agregar）。
9. 串联单及其提示点（guion_cue）和检查清单（evento_verificar）。

## 3. 邀请任何人**之前**先检查

发出去却打不开的链接或二维码，比不发还糟。
- 外部连接：acceso_remoto_estado（隧道正常，地址是最终地址）。
- 如果要**打印**二维码，或提前几天发送邀请：地址要**固定**（自有域名或保留的子域名：acceso_remoto_probar_direccion、acceso_remoto_dns_verificar）。如果之后地址变了，所有东西都得重印、重发。要告诉操作员。
- 摄像机和音频：foto_programa / foto_fuente；能看到、能听到（夜里不要让扬声器出声：用 audio_measure 测量）。
- 一位测试嘉宾：用另一台设备或浏览器打开会议室链接（room_link），并在有人在里面时运行 invitado_prueba（回声和网络）。
- 活动网页能打开（evento_web），并显示应该显示的内容。
这之后才发邀请（每人一份 invitacion：文字、链接和二维码），并说明如何发送（邮箱、WhatsApp），或者如果配置了通知器，就用它发出。

## 4. 彩排

**始终**建议彩排：evento_ensayo_rapido（不等待地走一遍串联单），更好的是用 evento_correr {accion: arrancar, ensayo: true} 做一次真正的彩排。告诉对方哪里出了问题，并修好。

## 5. 交付

完成后，在一条消息中给出：
- 活动网页的**链接**（evento_web），让对方打开。
- 每个人要用的链接：嘉宾会议室、提词器、控制台、观众。
- 还没完成的事项，以及只有人才能确认的事项（evento_chequeo_ver）。
- 活动当天如何开始（“导播”卡片：“开始串联单”）。

## 图片

背景和垫片画面：JPG，最大 1920×1080，小于 500 KB（一张 8 MB 的图片在网页和观众手机上加载很慢）。如果找到的图片太大，用之前先缩小（程序自带 ffmpeg：`ffmpeg -i in.png -vf scale=1920:-1 -q:v 4 out.jpg`）。标志用透明背景（PNG）。说明每张图片的来源，以及能否使用。

## 不问不做的事

开始播出、推流、发送邀请、删除或覆盖已有的场景、花钱或创建账号。新活动**从零开始**：除非对方要求，不要复用或修改其他活动的场景。
